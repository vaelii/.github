# Support

Organization-wide default. A repository may override it with its own
`SUPPORT.md`.

## Getting help

- **Read the docs first.** The engine's
  [`docs/`](https://github.com/vaelii/vaelii/tree/main/docs) is the manual —
  [`docs/index.md`](https://github.com/vaelii/vaelii/blob/main/docs/index.md)
  maps every subsystem note, `docs/api.md` is the public surface, and
  `docs/glossary.md` defines the vocabulary. `vaelii-foreign` documents its
  readers in its own `docs/`, `vaelii-agents` its providers and tools in
  `docs/llm.md`, and the storage adapters document themselves in their READMEs.
- **Questions:** open an issue on the relevant repository and say it's a
  question. Discussions are not enabled. Search the tracker first — it may be
  answered already.
- **Bugs:** open an issue on the repository where the bug lives, using the issue
  template. Include the version or commit, the backend if one is involved, and a
  reproduction.

## What's not a support channel

- **Security issues** — do not open a public issue. See
  [`SECURITY.md`](SECURITY.md).
- **Commercial licensing / private inquiries** — **support@vaelii.com**.

Vaelii is a small project; help is best-effort, with no response-time guarantee.
